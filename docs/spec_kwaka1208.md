# 「あの日の空 — Birthday Sky」現行仕様書

## 概要

生年月日・時刻・観測地点を指定し、その瞬間の全天星図をブラウザで再現するWebアプリです。表示は天体の位置・等級・空の明るさを反映する観測表示へ一本化しています。

## 入力

- 日付：1900-01-01〜2100-12-31
- 現地時刻：必須
- 観測地点：地名検索、現在地、または緯度経度の手動入力
- IANAタイムゾーン：地点選択時に自動取得、手動変更可能
- 最大表示等級：1.0〜6.5、0.5刻み

最大表示等級は数値が大きいほど暗い星を含みます。選択値と、薄明・月光から求めた自然限界の小さい方を実表示限界にします。

## 恒星データ

- 名称付き主要恒星：59星
- NASA HEASARC BSC5P：3.45より暗く6.5等級以下の8,132レコード（同一座標と主要恒星30秒角以内の重複は表示時に除外）
- 使用フィールド：J2000赤経・赤緯、V等級、B−V色指数
- B−V色指数から表示色を近似
- IAU 1976歳差モデルで観測日へ補正

生成済みカタログをアプリに同梱します。再生成は`npm run data:stars`で行い、NASA HEASARC TAP APIへ次のADQLを送信します。

```sql
select ra,dec,vmag,bv_color
from bsc5p
where vmag > 3.45 and vmag <= 6.5
```

BSC5PはNASAの観測ミッション固有データではなく、NASA HEASARCが配布するBright Star Catalogです。出典は[公式カタログページ](https://heasarc.gsfc.nasa.gov/W3Browse/all/bsc5p.html)へ明示します。

## 天文計算

- 太陽・月・水星・金星・火星・木星・土星：Astronomy Engine
- 恒星：地方恒星時と観測地点から地平座標を算出
- 地平線付近は標準大気差を近似補正
- 月相と月の照度を算出
- 太陽高度と月明かりから限界等級を概算

## 表示・操作

- 指定日時の太陽高度に応じた昼・薄明・夜の空色
- 等級に応じた星の大きさと、B−V色指数に応じた色
- 星座線、天体名、太陽・月・惑星のON/OFF
- ドラッグで方角を回転
- ホイールまたはボタンで拡大・縮小
- 表示リセット
- Fullscreen APIによる星空カードの全画面表示と終了
- 表示恒星数、月相、実際の限界等級を表示

## 外部サービス

- Nominatim：地名検索・逆ジオコーディング
- TimeAPI：緯度経度からIANAタイムゾーン取得
- Geolocation API：現在地取得

タイムゾーン取得に失敗した場合、旧地点のタイムゾーンを流用せず地点変更を中止します。

## 検証

```bash
npm run typecheck
npm run build
```

## 制約

- 過去の雲量・天候、地域別光害、建物・地形による遮蔽は未対応
- 地名検索、タイムゾーン取得、Webフォントにはインターネット接続が必要
- Fullscreen API非対応ブラウザでは全画面ボタンを無効化
